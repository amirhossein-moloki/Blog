# راهنمای جامع استفاده از رسانه‌ها (Media API Guide)

این مستند نحوه تعامل و استفاده از رسانه‌ها (عکس، ویدئو، صوت) در تمامی APIهای سیستم را تشریح می‌کند.

---

## 💡 معماری مدیریت رسانه دوگانه (Hybrid Media Architecture)

در تمامی سرویس‌ها و APIهای سیستم که با فایل‌های رسانه‌ای سر و کار دارند، نحوه ارسال و استفاده از مدیا به شکل **دوگانه (Hybrid)** طراحی شده است:

1. **ارسال مستقیم آیدی (Media ID):**
   اگر مدیا قبلاً در سیستم آپلود شده باشد (از طریق کتابخانه رسانه)، می‌توانید تنها **آیدی عددی** آن (مثلاً `12` یا `"12"`) را ارسال کنید.
2. **ارسال مستقیم فایل عکس/ویدئو/صوت (File Upload):**
   برای راحتی کار نیازی نیست ابتدا فایل را جداگانه آپلود کنید و آیدی بگیرید. به لطف کلاس اختصاصی `HybridMediaField` در سیستم، می‌توانید خود **فایل (Binary File)** را مستقیماً در همان درخواست ایجاد/ویرایش (از طریق فرم `multipart/form-data`) ارسال کنید. سیستم به صورت خودکار:
   - فایل را اعتبارسنجی می‌کند (حجم و پسوند/نوع فایل).
   - آن را در ذخیره‌ساز (S3 / Local) ذخیره می‌نماید.
   - یک نمونه `Media` جدید در دیتابیس می‌سازد.
   - آیدی رسانه ساخته‌شده را به صورت اتوماتیک به مدل مربوطه متصل می‌کند.

## 📋 لیست کامل APIهای دارای مدیا و شرایط استفاده

### ۱. کتابخانه اصلی رسانه‌ها (Media Library API)
* **آدرس:** `POST /api/medias/`
* **نوع درخواست:** `multipart/form-data`
* **پارامترها:**
  * `file`: فایل آپلودی (الزامی)
  * `title`: عنوان رسانه (اختیاری)
  * `alt_text`: متن جایگزین (اختیاری)
* **توضیحات:** این API مخصوص آپلود مستقیم رسانه جدید در کتابخانه مرکزی است و پس از آپلود، یک شیء کامل `Media` به همراه `id` آن برمی‌گرداند.

---

### ۲. مقالات و اخبار (Articles API)
* **آدرس‌ها:**
  * `POST /api/articles/` (ایجاد مقاله)
  * `PUT / PATCH /api/articles/{id}/` (ویرایش مقاله)
* **فیلدهای مدیا:**
  * **تصویر کاور:** هم فیلد `cover_image` و هم `cover_image_id` پشتیبانی می‌شوند.
  * **تصویر Open Graph:** هم فیلد `og_image` و هم `og_image_id` پشتیبانی می‌شوند.
* **نحوه ارسال:**
  * **ارسال آیدی:** `{"cover_image_id": 5, "og_image_id": 8}`
  * **ارسال مستقیم فایل:** در درخواست `multipart/form-data` ارسال فایل در `cover_image` یا `cover_image_id`.
* **نکته:** قانون اعتبارسنجی سیستم اجازه نمی‌دهد همزمان هم `cover_image` و هم `cover_image_id` مقداردهی شوند.

---

### ۳. پروفایل نویسندگان (Author Profiles API)
* **آدرس‌ها:**
  * `POST /api/authors/`
  * `PUT / PATCH /api/authors/{pk}/`
* **فیلدهای مدیا:**
  * **تصویر آواتار:** `avatar` و `avatar_id`
* **نحوه ارسال:**
  * **با آیدی:** `{"avatar_id": 10}`
  * **با فایل عکس:** ارسال فایل عکس در فیلد `avatar` یا `avatar_id`.

---

### ۴. دسته‌بندی‌های مقالات (Categories API)
* **آدرس‌ها:**
  * `POST /api/categories/`
  * `PUT / PATCH /api/categories/{id}/`
* **فیلدهای مدیا:**
  * **آیکون دسته‌بندی:** `icon` و `icon_id`
* **نحوه ارسال:**
  * **با آیدی:** `{"icon_id": 3}`
  * **با فایل عکس:** ارسال فایل آیکون در فیلد `icon` یا `icon_id`.

---

### ۵. پادکست‌ها (Podcasts API)
* **آدرس‌ها:**
  * `POST /api/podcasts/`
  * `PUT / PATCH /api/podcasts/{id}/`
* **فیلدهای مدیا:**
  * **تصویر کاور پادکست:** `cover_image` / `cover_image_id`
  * **فایل صوتی:** `audio_file` / `audio_file_id`
  * **فایل ویدئویی:** `video_file` / `video_file_id`
* **نحوه ارسال:**
  * **با آیدی:** `{"cover_image_id": 12, "audio_file_id": 45}`
  * **با فایل مستقیم:** ارسال فایل MP3/MP4/عکس به شکل مستقیم در فرم `multipart/form-data`.

---

### ۶. دسته‌بندی پادکست‌ها (Podcast Categories API)
* **آدرس‌ها:**
  * `POST /api/podcast-categories/`
  * `PUT / PATCH /api/podcast-categories/{id}/`
* **فیلدهای مدیا:**
  * **آیکون دسته‌بندی پادکست:** `icon` / `icon_id`
* **نحوه ارسال:** پشتیبانی از آیدی عددی و آپلود مستقیم فایل آیکون.

---

### ۷. گالری تصاویر (Gallery Items API)
* **آدرس‌ها:**
  * `POST /api/gallery-items/`
  * `PUT / PATCH /api/gallery-items/{id}/`
* **فیلدهای مدیا:**
  * **تصویر گالری:** `image` / `image_id`
* **نحوه ارسال:** پشتیبانی همزمان از آیدی رسانه موجود (`image_id: 15`) یا آپلود مستقیم فایل عکس.

---

### ۸. آپلود مستقیم ادیتور (CKEditor 5 Upload API)
* **آدرس‌ها:**
  * `POST /api/editor/upload/`
  * `POST /ckeditor5/image_upload/`
* **نوع درخواست:** `multipart/form-data` با فیلد `upload`
* **توضیحات:** این API ویژه ادیتور متنی است و فایل عکس فرستاده شده را پردازش و ذخیره کرده و URL آن را برای درج در متن بازمی‌گرداند.

---
